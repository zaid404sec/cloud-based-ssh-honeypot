Cloud-Based SSH Honeypot Using Cowrie

Overview

This project explores SSH threat monitoring using Cowrie, an SSH/Telnet honeypot deployed on Ubuntu Server in AWS EC2.

Objectives

- Understand SSH login attempts in a controlled honeypot environment.
- Record and inspect authentication events.
- Analyze honeypot logs for security insights.
- Explore cloud-hosted security monitoring.

Technology Stack

- Ubuntu Server
- AWS EC2
- Cowrie SSH Honeypot
- Python
- Linux
